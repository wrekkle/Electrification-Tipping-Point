# Licensing status

## Code

No open-source licence has been chosen for the code in this repository yet. Absent an explicit
licence, the code is provided for reading and review **without a grant of reuse rights**; do not
copy or redistribute it until the authors add a licence. This file will be replaced when that
decision is made.

## Data

The parking event data are published by the City of Melbourne under **CC BY 4.0**:

- City of Melbourne, *Parking bay arrivals and departures 2014*, dataset `mq3i-cbxd`,
  https://data.melbourne.vic.gov.au/explore/dataset/parking-bay-arrivals-and-departures-2014/

Redistribution of derived extracts requires attribution to the City of Melbourne and a link to
that dataset page. `data/sample/` and any file under `results/` that contains derived event
counts are such extracts.
