draft: the frozen manuscript, the current working draft and every earlier version stay in the
authors' local workspace and are not published here.

| object | status | location |
|---|---|---|

What is public here: the method and metric definitions (`../docs/method.md`), the data source and
processing rules (`../docs/data.md`), the reproduction steps (`../docs/reproduce.md`), and the
selected result files under `../results/`.

There is no published version. No preprint, no DOI, no acceptance record, and the current round
has not been submitted. Do not cite this repository as a published paper. If a version is
submitted or posted, it will be added here and this table will be updated with the venue and the
identifier.
