# Manuscript status

This directory is the single public entry point for the paper. It does not ship a
working draft: the current working draft, the frozen submission and every earlier
version stay in the authors' local workspace and are not published here.

| object | status | location |
|---|---|---|
| frozen submission (2026-03) | local only, never modified, not published | workspaces/main_paper |
| current working draft (rev8) | local only, under internal review, not a preprint | workspaces/paper |
| supplementary material (rev8) | local only | workspaces/paper |
| machine results behind the figures | published in summarized form | `../results/` |

What is public here: the method and metric definitions (`../docs/method.md`), the data
source and processing rules (`../docs/data.md`), the reproduction steps
(`../docs/reproduce.md`), and the selected result files under `../results/`.

No preprint, DOI or journal acceptance is claimed. When the authors decide to publish a
version, it will be added here and this table will be updated.
