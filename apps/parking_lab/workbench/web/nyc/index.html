      R0 · 观测重放 · 不参与选择

      M0 / M1 / M2 期望曲线与 n*（选择对象）

      曲线来自 runs/run_*.json 的 curve.total 与 choice 字段；n* 是期望成本 argmin。三种机制共用同一成本参数与网格，只替换生成机制。

      expected cost · M0/M1/M2

      固定配置评价（跨机制 · 登记充电位 · n=0 基线）

      把选择阶段冻结的 n 放到独立时间块上评价，并做跨机制评价：同一 n 在不同机制生成的世界里评价。必须同时看登记充电位（registered_ev_bays）与 n=0 基线（J_mean_at_0），否则无法判断成本差异来自配置还是机制。

      fixed_config_eval · 不参与选择

      稳健配置（robust_A / robust_B 分开命名）

      robust_A：先对 ω 求期望、再对机制/情景/θ 取最坏，是设计对象；robust_B：对单次实现取最坏，是压力测试对象，不是设计选择。两表不合并、不互相替代。

      robust_A / robust_B

      稳健 A · robust_A（设计对象）

      稳健 B · robust_B（压力测试对象，非设计选择）

      逐世界事后最优明细（读 panels.hindsight.csv，仅诊断）

      本表逐行来自 v3 的 export/t63_per_world_hindsight.csv 真实 CSV，不使用固定配置评价兜底。hindsight_gap = 固定 n 的 J_fixed − 该世界最小 J（≥0）；只做诊断，不参与选择。

      仅诊断 · 逐世界 hindsight

      留出验证 A / B 两表与噪声底

      A 给定留出周的观测计数，只评形状；B 用训练期信息同时预测数量+形状。A 不得当作 B，两表不合并。噪声底给同一观测在重复生成下的波动尺度，不构成真实数据上的置信区间。

      holdout A / B · noise floor

      留出 A（给定计数，只评形状）

      留出 B（训练信息预测数量+形状）

      噪声底（同观测重复生成波动）

      归因对照与选择诊断

      归因按"每次只改一个机制"的成对对照展示；同向偏差不等于某一机制主导，缺失值显示“未定义”。选择诊断给出登记充电位与观测/未约束生成峰值，帮助判断机制差异是否可能来自服务样本与需求定义差异。

      attribution · selection diagnostics
