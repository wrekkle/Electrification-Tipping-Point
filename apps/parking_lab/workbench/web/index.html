数据来源与情景

车流与需求由后端按配置生成（合成仿真，随机种子固定）；EV 比例、充电概率、目标电量属于声明的需求情景，不是观测到的 EV 行为。停车到达与停留来自模型生成的事件流，回放只展示已入账账本。

指标口径

  • 拒绝率 = 被拒到达 / 到达总数；分母含所有到访（含被拒）。
  • 充电完成率（全需求）= 完成充电请求 / 需充电请求；尚在场未交付单独列为待交付，不计入已离场失败。
  • 能量账本：需求 = 交付 + 被拒 + 离场缺口 + 在场待交付（平衡误差在模型内校验）。
  • 时间平均占用率 = 占用车位分钟 /（车位总数 × 已运行分钟）。
  • 成本 v2：分项唯一入口，缺失参数为 null；占桩归因与转移支付不进总成本。

回放与时钟

仿真时钟由后端推进；浏览器每秒轮询同一状态。暂停后所有视图停止推进；倍速改变后各视图同步；单步按步长推进一次。回放位置是后端在事件批次处理完时记录的真实状态快照：顶部时钟显示该快照的实际时刻，点阵、占用/充电数量、功率、累计电量、趋势图与热力图截止、事件列表都来自这同一份快照；同一时刻的多个事件合为一个快照，不插值、不产生到达/离场/充满事件。快照未保存的字段（时间平均占用率、成本、大场地的车辆级明细）明确显示“该历史时刻未记录”。

限制

合成仿真不证明现实 EV 行为；缺少真实车牌/摄像头数据；成本参数多数未知；热力图分辨率受后端帧采样限制（大场地与大总时长自动降采样）。
