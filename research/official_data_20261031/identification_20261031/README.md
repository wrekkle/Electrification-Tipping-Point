## T28 关键结论（詳見机制审计与 registry）

- **可得**：台湾电动小客车保有量序列 76,525（2024-06，審計部）→ 87,182（2024-09，運研所/公路局）→ 110,768（2025-07，國發會引交通部）→ 130,278（2026-02，立法院/交通部）；公共充电枪 9,564（2024-06）→ 12,334（2025-07）→ 15,328（2026-02）；车桩比 9.0:1→8.5:1；法定充电专用位比例 公有路外 ≥2%、民营 ≥1%；市售比**目标** 2025=10%、2030=30%、2035=60%、2040=100%。
- **不可得（UNVERIFIED，不得编造）**：实际新車市售比（審計部报告标题称未达目标/负成长，但 PDF 下载端点返回 HTML，212/950 bytes）；公共充电桩使用率；场站 EV 到访份额 p_EV_arrival。
- **禁止混用**：保有量份额（2024-09 全国 1.04%）≠ 新车市售比 ≠ 公共充电使用率 ≠ 场站到访份额；法定充电位比例（2%/1%）与枪位比（1,888/80,221=2.35%）也只是供给指标。
