Purpose: allow an independent reader to rebuild every number, figure and table of the
rev5 draft and SI from the raw source plus the declared scenario. Nothing here is typed by
hand: hashes and inventories are generated by collect_repro.py; page/word counts are taken
from the build manifests and the Word repagination pass.

See environment.json. Recorded: python 3.12.14, numpy 2.3.5, matplotlib 3.11.2,

## 3. Seeds and resampling

- All engine runs: seed 20261031.
- Bootstrap: percentile, 1000 resamples, unit = independent stream (site-day).
- Figure-side bootstrap (F2, F4): same percentile scheme, 1000 draws, seed 20261031; the
  plotted intervals are display recomputations on the same rows, the confirmatory values
  are the engine's M/m_summaries.csv.
- The scenario layer (20% charging-bay share, 7 kW / 22 kW connector, feeder rules,
  14 +- 6 kWh per charge-requesting EV) is a declared assumption, not a measurement: the
  source has no charging field. Every run labels this scenario in its manifest.

the directories actually present. Family outputs:
