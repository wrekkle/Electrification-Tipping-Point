# 事件语义与窗口处理核查（R8-F，摘要）

类型: 研究分析
状态: 生效（2026-10-31）

- 行语义：一次停车占用事件（到达+离开成对）；字段 ArrivalTime / DepartureTime / DurationSeconds / BayID / AreaName / InViolation。
- 全量源：13,503,655 行、5,228 BayID、335 street×side 段、366 个本地日期（2014-01-01..2015-01-01 两端点均有记录；2014 非闰年）。
- 数据质量：负停留 7,670（0.057%）；InViolation 1,505,691（11.15%）；ParkingEventId 不唯一（13.5M 行仅 168,905 个值，按设备内序号）→ 契约 event_id 用窗口行号唯一化，源 ID 仅追溯。
- 研究窗口：2014-01-06..2014-03-31（85 日）。窗口导出 236,819 行 / 24 场站 → 取 10 场站 185,552 行 → 剔除 2 条缺离场时刻 → 185,550（= 契约）。
- 删失：窗口内无期初占用、无窗口后离场；跨午夜 2 条按到达日归档；缺离场 2 条剔除并登记。
- 事件进入请求流的方式：到达时刻=请求到达，停留=占用时长，场站=池，泊位数=池容量；EV/补能/能量为情景层（见 FIT_FOR_MODEL.md §6）。
