## 3. 识别方案：解法 B + 解法 C（核心）

### 3.1 解法 B：部分识别，只给界，不猜模型

思路：只用**会计恒等式 + 可观测总量 + 停留时长的合理范围**，把 q 夹在区间里。不需要知道到达过程、不需要分布假设。

可观测：占用曲线 Y_t、车位数 N、充电位数 m、时段长度 Δ、充电桩状态或电量表（若有）。

**第一步，算累计占用车时（berth-time）**：

~~~
B_time = Σ_t Y_t · Δ
~~~

**第二步，用停留时长范围把到达量夹住**（Little 律的区间版）：

~~~
A ∈ [ B_time / d_max ,  B_time / d_min ]
~~~

d_min、d_max 是停留时长的合理上下限（可从场地类型、调查或同类文献取；这是 B 唯一的假设）。

**第三步，用充电会话数夹 q**。若桩后台能给出充电次数 n_s：

~~~
q_lo = n_s / (r · A_hi) = n_s · d_min / (r · B_time)
q_hi = min( 1 , n_s / (r · A_lo) ) = min( 1 , n_s · d_max / (r · B_time) )
~~~

若拿不到桩状态、只有电量表，则用 n_s ≈ E_total / ē（ē 为平均单次充电量，需给范围），界会变宽但方向不变。

**B 的输出**：q 的区间 [q_lo, q_hi]，以及"占位不充电"的下界（充电位被占时长 − 充电时长）。**结论写法**：只报"在 q ∈ [q_lo, q_hi] 内都成立"的结论；若结论在区间内翻转，就如实写"不可判定"。

**B 的优点**：不依赖生成模型，审稿人很难说"你的分布假设错了"；**缺点**：界可能很宽，宽到结论无意义——这正是要靠 C 收窄的地方。

### 3.2 解法 C：从占用序列反演 q

思路：建一个能生成"占用曲线"的生成模型，用观测反推参数。这是**结构性识别**，比 B 强，但依赖模型假设。

最小生成模型（含占位不充电）：

~~~
A_t   ~ Poisson( λ_t · Δ )                       到达强度（分时段）
R_t   ~ Beta 或二项                                EV 比例
c_i   ~ Bernoulli(q)                              到达的 EV 是否要充电（隐变量）
d_i   ~ LogNormal(μ_d, σ_d)                       停留时长
e_i   ~ LogNormal(μ_e, σ_e)                       充电电量
t_leave      = t_arrive + d_i
t_charge_end = t_arrive + min( e_i/(η·P), d_i )
Y_t = #{ i : t_arrive ≤ t < t_leave }            占用
S_t = #{ i : c_i=1 且 t_charge_start ≤ t < t_charge_end }   充电中
W_t = #{ i : 停在充电位 且 未插枪 }               占位不充电（新状态）
~~~

似然没有解析式（状态空间大），用两类实现：

- **模拟推断（ABC / 合成似然）**：从先验抽 (q, λ, θ_d, θ_e) → 仿真出 (Y, S) → 用摘要统计比距离 → 保留近邻得后验；
- **简化代理**：把一天切成 15–30 分钟格子，用泊松-二项混合近似，再用 MCMC；精度换取速度。

摘要统计建议：分时段占用率均值/方差、充电位忙碌率、占用时长分位数、换手率、连续满位时长、占位不充电时长占比。

**可识别性诊断（必做）**：比较后验宽度与先验宽度。若后验≈先验，说明这套观测对 q 没信息量，C 失败，只能靠 B 的界——这个诊断要写进论文，不能藏起来。

**校验**：SBC（simulation-based calibration）——生成 100 组已知 q 的数据，看 90% 后验区间覆盖真值的频率是否约 90%。

### 3.3 B 和 C 怎么配合（这才是"解 BC"）

不是二选一，而是**三角验证**：

1. **B 给外包络**：模型无关的区间 [q_lo, q_hi]；
2. **C 给内部估计**：模型后验 p(q|数据)；
3. **一致性检验**：C 的后验质量有多少落在 B 的区间内。若 ≥90%，说明模型假设与会计恒等式相容，可以报 C 的点估计 + B 的界；若 <90%，说明 C 的模型误设（比如 λ 或停留分布错了），**论文必须报 B 的界，并说明 C 不可信**；
4. **双区间传播**：把 q ∈ [q_lo, q_hi] 与 q ~ 后验分别喂进 v2 仿真，得到两个 ETP 区间：**识别稳健区间**（B，结论最保守）与**模型后验区间**（C）。论文报两者的交集，并说明"交集之外的部分依赖模型假设"。

这个"外包络 + 内估计 + 一致性检验"的结构就是本方案的方法贡献：现有配置论文要么用点估计、要么做敏感性，很少有人把识别不确定性与模拟不确定性分开报。

### 3.4 数据三档（B 和 C 分别需要什么）

| 档 | 数据 | B 能给 | C 能给 | 结论强度 |
|---|---|---|---|---|
| A（理想） | 占用快照 + 桩会话（起止、kWh、桩号）+ 容量/功率 | 窄区间 | 后验 + 可识别性诊断 | 强 |
| B（现实） | 占用快照 + 桩"是否在充电"状态位 + 容量 | 中等区间 | 较宽后验 | 中 |
| C（最差） | 只有占用快照 | 宽区间（靠 d_min/d_max） | 大概率不可识别 | 弱，只能写稳健性 |

现有数据判断：稿子里的数据是第三方平台（聚美/腾讯云市场）的实时空位与容量，属 C 档；**桩会话/状态要单独向运营方要**，这是最大外部依赖。

### 3.5 最小可行实验（MVE，两周，go/no-go）

用公开 ACN-Data（有会话级记录）做闭环，**B 和 C 都测**：

1. 从会话记录算真值 q：某站点某时段，EV 到达里实际插枪的比例；
2. 丢掉会话级信息，只保留：按容量聚合的占用曲线 + 充电次数 n_s + 累计占用车时 B_time（模拟 A/B 档数据）；
3. 跑 B：用 3.1 的公式算 [q_lo, q_hi]，看真值是否落在区间内；
4. 跑 C：反演后验，看中位误差与 90% 区间覆盖；
5. 做一致性检验：后验落在 B 区间内的比例；
6. 换 3 个站点 × 3 个时段重复。

**判据（全部满足才 go）**：
- B：真值落在区间内的比例 ≥ 8/9；
- C：中位误差 ≤ 0.10，90% 区间覆盖 ≥ 85%；
- 一致性：后验落在 B 区间内的质量 ≥ 90%；
- 方向一致：3 个站点的 q 排序稳定。

**失败退路**：C 不可识别 → 论文只报 B 的界 + 在界内结论稳健性；B 的界太宽 → 降级为"情景 + 敏感性"，同时把"数据缺失导致不可识别"本身写成论文的局限与呼吁（这在应用类期刊是可接受的）。

### 3.6 接入创新点 10：ETP 的双区间

~~~
ETP_robust  = [ min ETP(q), max ETP(q) ] ,  q ∈ [q_lo, q_hi]        （B 口径）
ETP_post    = ETP 的 90% 分位区间 ,        q ~ p(q|数据)            （C 口径）
最终结论    = 两者的交集，并注明交集外依赖模型假设
~~~

这样"0.7 拐点"就变成"在数据能支撑的范围内，拐点在 [0.6, 0.8]"——这是审稿人无法用"参数是猜的"驳倒的写法。

## 4. 支撑一：A10 统计判定（与 B+C 并行）

- 现状：静态层已实现 block bootstrap + max-t 置信集、g(r)、三区；v2 层缺（只有 8 天、3 个 r）。
- 要补：v2 场景 ≥300 天、r 覆盖 0.2–1.0、两场地；v2 版置信集/三区/CVaR。
- 关系：B+C 给"q 的识别不确定性"，A10 给"给定 q 时 ETP 的统计不确定性"，两层合成才是最终结论。

## 5. 支撑二：A7 容量能量 + 占位不充电（机制章）

- v2 已有：设备/覆盖/并发/功率/馈线/能量交付、π_S/π_F/π_θ 三条规则。
- 要补：状态机加"停在充电位不插枪"（3.2 的 W_t）；指标加**充电位浪费率** = W 占用时长 / 充电位总时长。
- 实验：q × θ × r 三维，回答"共享是不是免费的午餐"；预期方向：q 越低、π_F 越亏，最优 θ 随 q 上升。
- 风险：参数多，必须配 §3 的 q 区间，否则回到"猜参数"。

## 6. 支撑三：A11 分配与支付（政策章）

- 做法：把社会成本按群体拆开（EV/ICEV、高/低时间价值），报告"谁承担了成本"；再与运营者利润口径对照，说明转移支付与外部性的差别。
- 成本低（改输出维度），能回应"社会成本参数谁说了算"。
- 不做支付意愿调查，只在讨论里给边界。
