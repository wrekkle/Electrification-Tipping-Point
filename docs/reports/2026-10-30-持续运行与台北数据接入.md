## 3. 持续运行时钟语义

| 模式 | 语义 | tick 行为 |
|---|---|---|
| `realtime` | 1x：1 仿真分钟 = 60 实时秒（与墙上时钟 1:1） | `sim_dt_min = 实时秒 × 1 / 60` |
| `accelerated` | N×（0.1–86400）：`sim_dt_min = 实时秒 × N / 60` | 同上，N 由 speed 指定 |
| `paused` | 时钟冻结 | 只刷新参考时刻，不推进、不入账 |
| `resumed` | 恢复：从当前时刻重新起算，不补推进暂停区间 | 下一次 tick 用恢复后的实时差 |
| `replay` | 回放：不推进仿真 | 只由 `replay_step()` 按游标暴露已记录事件/批次 |

推进方式：`sim.advance(sim.time + Δ)`，从当前时刻向后推进；不重置 seed、不按数组索引重播轨迹。
账本守卫：每条事件分配单调 `seq`；`watermark = len(sim.events)` 记录已入账数量；
`len(sim.events) < watermark` 或事件时间倒退 → 抛 `ContinuousError("拒绝重复入账")`（测试 `test_rewind_guard_refuses_double_posting`）。
接口：`POST /api/advance {id, elapsed_seconds?}`（省略 elapsed 时用服务器单调时钟）、`/api/mode`、`/api/speed`、`/api/pause`、`/api/resume`、`/api/replay/start|step|exit`。
界面显示：当前模式徽标、倍速与语义、仿真时间、实时已推进、tick 次数、事件/已入账数、水位与 seq 区间、时钟来源、模式时延（实时 vs 期望）、回放游标。

## 4. 台北数据接入语义（datasource.py，只读）

消费文件：`data/<date>/parking_slots.jsonl`、`data/<date>/connector_status_long.jsonl`、`runtime/state.json`、`cohort.json`、`config.json`；不联网、不写采集目录、不补数据。

- 去重：按 `request_sha256`；同一哈希再次出现 = 源未更新（`status="duplicate"`、`is_new_data=False`），
  不重复计量、不推进"最后真实观测时间"。实测采集器 `duplicate_batch` 标记与哈希去重结果一致（4 个槽）。
- 失败批：`http_status != 200` 且无有效可用车位数 → `status="request_failed"`，单独计数，不当作新观测。
- 断档：相邻槽间隔 > 1 个 interval 时按 `round(Δ/interval)-1` 计漏采槽数，并与采集器 `runtime/state.json` 的 gaps 日志交叉核对。
- 新鲜度：`age = 当前UTC - 最后成功抓取时间`；`age ≤ 1×interval(300s)` fresh、`≤ 6×interval(1800s)` stale、更久 expired、无数据 missing。
  只读显示，不生成假更新（测试 `test_freshness_states_use_clock_and_never_fabricate`）。
- 语义约束（写入 API/界面/导出）：逐场停车余位 = 净占用变化，不是到达/离场；逐枪"待機中/充電中"不是空位、不是无需求、不是充完未走；
  到达率、离场率、停车时长分布、车型比例、充电意愿、被拒绝需求 = 不可识别（unknown）。
- 缓存：按文件 mtime/size 签名缓存解析结果；`/api/state` 内嵌摘要缓存 20 秒，`?refresh=1` 或 POST 指定 `now_utc` 时强制重算。

### 12.1 结论

- **⑤ realtime 恒为 1x**：`ContinuousEngine.effective_speed()` 只在 accelerated 返回所选倍速；realtime 无论配置/请求给多少倍速都按 1x 推进。界面「倍速/语义」显示"有效 1x（realtime 固定，所选倍速 Nx 不生效）"。
- **⑤ 暂停/改速/切模式先结算上一区间**：新增 `settle()`；`pause()/set_speed()/set_mode()/start_replay()` 先用**旧模式、旧倍速**把"上次 tick/结算到操作时刻"的墙上时间推进完再切换，不再丢最后一次轮询到操作时刻的区间；`resume()` 只重置参考时刻，不补算暂停区间；单调 seq + 已入账水位守卫不变（回退即报错），不重复入账。
- **⑤ 有限窗口写清**：`status()["window"] = {finite: true, horizon_min, stops_when, note}`；界面新增「窗口到期」一行与说明"仿真时长…到期后 tick 自动停止（finished），不是无限持续运行"。可注入 clock 仍由构造参数 `clock=` 支持（测试用闭包时钟）。
