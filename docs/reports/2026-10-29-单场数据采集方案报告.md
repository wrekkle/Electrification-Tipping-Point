## 0. 一页结论

**要做什么**：在广州选 **1 个"停车场内有充电桩"的场**，每 5–10 分钟记录 **两行计数**（停车场占用/剩余车位数、充电枪空闲/充电中/故障数），持续 4–6 周，配静态信息（车位数、枪数、功率、价格）。

**从哪来**：停车侧用**广州泊车**（市停车平台，显示余位），充电侧用**粤易充**（广东省统一充电服务平台，显示场站实时桩状态），选两个平台都能查到的同一个场。

**成本**：零经费；开发 2–3 天，挂机 4–6 周，分析 2 周。

**产出**：能跑 B（部分识别）+ C（反演）的最小数据集；论文写成**单场案例 + 方法贡献**。

**请上级批三件事**：① 批准广州范围内选 1 个场并做低频抓取；② 确认合规口径（平台条款、学校要求）；③ 确认论文按单场案例写，不承诺 638 场大样本。

**关键未知**：两个平台是否真的显示我们要的字段、是否稳定可抓。第 1 周先手动试抓一天验证，不通过就换场或换城市——**这是本方案唯一的 go/no-go 点**。

## 1. 为什么不是五项数据

五项（占用快照、充电会话、桩状态、容量、场地属性）是"有运营方配合"的理想版，自己采不现实，也不必要：

| 项 | 自己采怎么办 |
|---|---|
| 1 占用快照 | 广州泊车余位，脚本抓 |
| 2 充电会话 | 不采明细，用"充电中数量"的上升沿估会话数 n_s |
| 3 桩状态 | 粤易充桩状态，脚本抓 |
| 4 容量/功率 | 平台页面/现场看，静态记一次 |
| 5 场地属性 | 现场看 + 地图，静态记一次 |

**能省掉 2 的原因是**：B 的公式只需要"充电次数"和"占用车时"两个总量，n_s 可以从充电中数量的上升沿近似；C 也只需要占用曲线，不需要逐车明细。

## 2. 要采什么（字段表）

## 3. 选场标准

1. 停车场内有充电桩，且**两个平台都能查到**；
2. 车位数 20–200、充电枪 ≥4（太少估不出 q）；
3. 需求有日变化（写字楼、商场、医院、地铁周边），不要选几乎不变化的内部专用场；
4. 步行或地铁可达，能去现场核对一次（车位/枪数/价格）；
5. 避开近期改造、施工、限流的场。

**验证方法**：手动查两个平台各 3 次/天 × 1 天，确认字段存在、数值合理、时间戳能对齐。

## 4. 怎么采

- **频率**：5–10 分钟一次，24 小时不停，4–6 周（覆盖至少 1 个完整周末 + 1 个节假日）；
- **方式**：Python + requests/定时任务，按天存 CSV；低频、单 IP、串行；
- **时间戳**：统一北京时间，记录抓取时刻与平台数据时刻（若平台显示"更新于"）；
- **缺测**：留空不插值，记录失败原因；
- **数据量估算**：6 周 × 288 次/天 ≈ 1.2 万行/场，很小。

## 5. 质量判据（验收）

| 指标 | 标准 |
|---|---|
| 字段非空率 | ≥99% |
| 缺测率 | <5% |
| 连续缺失 | 单次不超过 30 分钟 |
| 与人工抽查一致率 | ≥95%（每天人工记 3 次对照） |
| 覆盖 | 至少 1 个周末 + 1 个节假日 |
| 时间对齐 | 两平台时间戳差 <2 分钟占比 ≥95% |

不达标的处理：先修脚本；仍不达标换场；连续 3 天不可用则启用退路。

## 6. 分析怎么用（B/C 映射）

- **B_time** = Σ 占用数 × 采样间隔 → 到达量区间与 q 的界；
- **n_s** ≈ 充电中数量的上升沿个数（同时进出会低估，用换手率修正）；
- **占位不充电** = 充电枪被占时长 − 实际充电时长（由充电中数量积分）；
- **C**：占用曲线 → 到达强度、停留分布、q 的后验；充电枪曲线 → 充电侧校验；
- q 的区间/后验 → 喂进 v2 仿真 → ETP 区间。

## 8. 退路

| 情况 | 处理 |
|---|---|
| 粤易充拿不到枪状态，只有站级总数 | 用站级空闲/占用总数，B 变宽，C 只做充电侧 |
| 广州泊车余位不可得 | 只采充电侧，B 靠 d_min/d_max 宽界 |
| 两个都不稳定 | 换场；仍不行换城市（深圳/佛山有类似平台） |
| 完全采不到 | 用公开数据集（UrbanEV/4TU/ACN）写方法论文，本地只做情景 |

## 9. 风险与合规

- **平台限制**：低频、串行、遵守 robots 与用户协议；不绕过登录/验证码；被限制就停并换源；
- **合规口径**：只存计数，不存车牌、手机号、用户 ID 等个人信息；数据仅校内研究使用；发表时说明来源与获取方式；
- **平台改版**：字段可能变，脚本要能报警；
- **单场外部有效性**：论文明写"单场案例，结论外推需谨慎"，用公开数据做外部校准。
