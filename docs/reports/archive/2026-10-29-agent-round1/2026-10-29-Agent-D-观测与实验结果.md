## 3. 状态—字段—可观测边界（给后端和采集的硬约定）

1. 潜在状态按 S0–S8 分；只保留站级计数时，I1–I7 七组不可区分：非 EV 占用与 EV 未插枪（都只减少余位）、插枪等待/供能/暂停（平台常合并为“充电中”）、完成仍停与供能（会话未关闭）、故障有车/无车、会话数、潜在需求、闲占率。
2. 因此 `会话数`、`闲占率`、`潜在需求` 不是站级计数的函数。E1 给出反例：同一快照对应 1 次与 2 次会话。
3. 逐枪状态只解决会话与状态切换，不解决“充电位上是否有非充电车”；闲占率仍需 L3 的位-枪对应与独立占用校验。
4. 能量只能在 L3 得到；没有能量字段时，能量交付、M05、M06 只能是模型量，必须标记。

指标侧：M01（接纳率）与 M02（服务成功率）分母不同；M06（已接纳缺口）与 M07（拒绝缺口）必须分账，分母分别是已接纳需求与全部请求；E3 用 c_gap=c_ref=2 演示了系数相等时两笔缺口在总成本里不可区分；M12（最弱群体）与 M13（总成本）并列，E3 给出“总成本更低但最弱群体更差”的具体数值。等待与充后停留只算占用机会，不算浪费。

规则侧：R1–R4 的不变项是 N、枪数、枪-位对应、需求序列、成本系数与选位规则。E4 说明选位规则本身能产生 57–244 元/日的差异，超过某些规则效应，所以不固定选位就无法把差异归给共享政策；宽松情景下 R3/R4 与 R1 完全不可分辨，紧张情景下 R3 比 R1 贵 225.7 元/日。移动设备按并发、覆盖、巡游时间、馈线与额外成本单列情景。

## 4. 留出、B/C 与 ETP 的现行口径

- 时间留出（前 7 日调参、后 3 日评价）与场站留一；留出日不进任何调参。E6 实测：日成本 SD=545、2% 误差需约 314 个独立日，因此“4–6 周一定够”不成立，必须用日间 SD 反推。
- 高频快照不作独立样本：E6 显示会把 SE 缩小 13 倍。
- B 区间给边界（依赖去重、EV 分母与未观测请求的界）；C 后验给模型结论；两者并列报告，不取交集。E7 的机械交集排除真值 0.6，是反例而不是证明某一方正确。后验变窄不等于识别：把 E 固定成 480 才得到 0.268–0.335 的窄区间，而同一 C=144 也由 E=240、q=0.6 生成。
- ETP 只报网格上的窗口集合（可多个、可为空），稳定性用 bootstrap 纳入频率；不外推网格之间。

- **未做**：任何真实平台数据校验；本轮无采集数据，所有数值是合成情景。
- **未做**：大型 ABC、SBC、在线学习；B/C 只用合成算例演示口径，未实现完整后验。

- **未做**：方法新颖性判断，归贡献查新（Agent C）。
