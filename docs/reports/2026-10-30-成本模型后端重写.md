## 反事实运行器（追加）

- 入口：`costs.run_paired_occupancy_counterfactual(config, intervention, arrivals=None, arrivals_b=None)`，干预类型 `INTERVENTIONS = {overstay_after_complete, no_charging_demand}`；同一外生到达流只生成一次并复用于两侧（A=允许占位、B=及时释放），`Simulation(intervention=...)` 只改被干预的占位规则，其余决策规则不变。
- 返回：`accepted / hashes_equal / traffic_hash_a / traffic_hash_b / cost_a / cost_b / delta_total / attribution{reason, occupancy_minutes_a, occupancy_minutes_b, released_minutes_by_reason} / resources{power_released_kw_min, connector_released_min, bay_released_min} / missing_parameters / complete`。`delta_total = C_A - C_B` 只作归因，不进入任何 total；哈希不等时 `accepted=false`、`delta_total=null`，不返回差值。
- 手算算例（1 车位 1 枪、7 kW、600 TWD/h、13 min 失败耗时）：
  - overstay_after_complete：A 侧 EV 充满后滞留到 60 min，ICE 在 20 min 到达被拒（130+4.8+3=137.8），B 侧 8.57 min 即释放、ICE 停入；两侧运营成本同为 46.0，`delta_total=137.8`，B 的 overstay 分钟数=0。
  - no_charging_demand：A 侧无充电需求电车占枪位、需充电电车被拒（170.8+42.5=213.3），B 侧无充电需求车不占带枪位而被拒（137.8）、需充电车充 3 kWh（53.0）；`delta_total=22.5`，B 的 no_charging_demand 分钟数=0。
- 归因不二次计账验证：基准运行 `total_cost == sum(cost_items)`，`cost_attribution.occupancy_impact` 保持 null，`occupancy_impact` 不在 `COST_ITEMS` 内；runner 的 `cost_a` 与基准 total 逐位相等。
- 哈希拒绝：把一条到达时刻从 0 改成 1，`hashes_equal=false`、`accepted=false`、`delta_total=null`。
- 实测：`python -m unittest apps.parking_lab.workbench.tests.test_costs.CounterfactualRunnerTests -v` → `Ran 5 tests ... OK`；全量 `discover` → `Ran 80 tests in 2.483s / OK`（含 sim-runtime 新增 test_runtime）。

## 成本核心修复（追加：items 1-4、8）

日期: 2026-10-30；负责人: cost-core；范围: `costs.py`、`simulation.py`、`config.py`、`tests/test_costs.py`。
本节取代上文与本节冲突的旧口径（尤其"无排队 ⇒ Δt=0"、上节反事实手算 137.8 / 22.5 两组数字，以及"本仿真无挪车机制"）。

### 改了什么

1. **动力类型与充电需求分离**（`simulation._record_rejection_cost`）：被拒车辆的能耗公式由 `is_ev` 决定（电车 → `ev_detour_energy` 电耗；油车 → `ice_vehicle_operating` 燃油），是否产生缺电分项由 `is_ev and needs_charge` 决定。无充电需求电车 `ev_residual_trip_loss=0`，但仍计时间/电耗/外部成本；`cost_kind` 现在只有 EV/ICE 两种动力类型，不再把"电车无需充电"记成 ICE。
2. **release_after_complete 挪车反事实**（`simulation._release_completed`、`CostLedger.add_relocation`）：
   - 只有存在空闲普通位（`bay >= charging_bays`）才挪车；挪车后车辆继续占普通位，`departure_min` 不变、不标 departed、不产生失败行；`released_min=relocation_min`、`relocation_status="relocated_kept_until_departure"`。
   - 无普通位时不挪车、不释放，`relocation_status="blocked_no_ordinary_bay"`，并记 `release_blocked` 事件；runner 返回 `delta_total=null, complete=false, not_implemented="no_ordinary_bay"`，不把"没发生"报成 0。
   - 资源分开记账：`attribution.resource_minutes{power_kw_min, connector_min, charged_bay_min, ordinary_bay_min, relocation_moves}`，`attribution.relocated_vehicles` 记每次挪车的 from/to/time。
   - 挪车成本按次计（`relocation_cost_per_move`）：参数 null ⇒ `relocation_cost=null`、`total=null`、`complete=false`，并进 `missing_parameters`；已知时计入 total（total = 分项和 + 挪车成本）。
   - 配对反事实仍用 traffic_hash 校验；占用差只进 attribution。power/connector/charged_bay/ordinary_bay 分别比较（`resources.connector_released_min / charged_bay_released_min / bay_released_min / ordinary_bay_minutes_delta / relocation_moves_b / relocation_blocked_b`）；功率释放量在充满后自动发生、干预不额外改变，保持 null。
3. **实时累计截断**（`costs.occupancy_minutes`、`costs.transfer_amounts`）：缺省只累计到 `sim.time`，在场车辆不再按计划停留时长/完整窗口统计；预计最终值单列在 `report["projected"]`（含 transfers、occupancy_minutes_by_reason、resource_minutes）。`transfer_amounts(..., until_min=)` 为显式实时口径。
4. **离场缺电不再隐含零后续**（`simulation._record_departure_cost`）：删除 `intervals=[]/detour_km=0` 的零假设，改为 `intervals=None`（时间未知）+ `detour_km=UNKNOWN_DETOUR`（绕行距离无观测，不回退到 `detour_km_per_failure` 当作已知），因此 `user_time/ev_detour_energy/ev_external/total` 为 null 并进 `missing_parameters`；有依据的缺电量分项（替代补能价差、剩余行程损失）仍可算。
5. **单位与非法输入**：`maintenance_per_bay_day` 的"位"=带枪设备位（`chargers`），按设备数逐日相乘（`maintenance_per_kwh × kWh + maintenance_per_bay_day × 天 × chargers`）；`CostLedger.summary` 缺 `chargers` 直接报错，避免静默按 0 或按全场总额算。`depreciation_life_years<=0` 在 `CostConfig.parse` 阶段 `ValueError`（原先 0 可通过并在 capex 分摊时除零）。

### 手算校验（tests/test_costs.py 逐项断言）

- 电车无充电需求被拒（`n_spaces=0`、detour 2 km、0.18 kWh/km、5 TWD/kWh）：`ev_detour_energy=1.8`，`ev_residual_trip_loss=0`，`ice_vehicle_operating=0`，`user_time=130`。
- 挪车（2 车位、1 带枪位、7 kW、strict、挪车 10 TWD/次）：A 允许占位 total=170.8+46.0=216.8；B 及时释放 total=137.8+56.5+10=204.3；`delta_total=12.5`（仅归因），B 侧 connector 释放 21.4286 min、普通位占用反而多 11.4286 min。
- 无普通位：车辆仍在原带枪位，`released_min=null`，`relocation_count=0`，runner delta=null/not_implemented。
- 未知挪车成本：`relocation_cost=null`、`total=null`、missing 含 `relocation_cost_per_move`。
- 实时截断：计划停 120 min、推进 1 min ⇒ 占用 1 min、停车费 40/60 TWD；`projected` 另给 60 min / 40 TWD。
- 按位维护：chargers 1→2 时 maintenance 恰好翻倍；chargers=0 时按位项为 0。
- `depreciation_life_years=0` 抛 ValueError；=5 正常。
