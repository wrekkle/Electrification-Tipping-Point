# docs 放什么

类型: 目录说明
状态: 生效
负责人: tho25
日期: 2026-10-29

只放管理类文档：说明、待办、进度、方法、生成报告。研究方案与历史记录在 `research/`、`plan/`，
不要搬进来。规则见 [AGENTS.md](../AGENTS.md)，写法见 [DOC-STYLE.md](methods/DOC-STYLE.md)。

| 文件/目录 | 放什么 | 命名 |
|---|---|---|
| `TODO.md` | 唯一待办登记处，分"还没做 / 未解决 / 已完成" | `T<号>`、`U<号>` |
| `PROGRESS.md` | 当前进度的唯一入口，一页说完现在在哪 | 固定名 |
| `methods/` | 按需读的方法文档，只有三份 | 固定名 |
| `reports/` | 报告归档：脚本生成的三份检查/字数报告，以及人写的研究方案 | `YYYY-MM-DD-主题.md` |
| `reports/archive/` | 过时提示词与阶段交付，保留历史证据 | `<日期-阶段>/` |

当前阅读入口是 PROGRESS、TODO、总体规划和最近的复验报告。提示词放在对话；同阶段由验收者集中追加既有报告，不按 Agent 增加文档。首轮 12 份材料已归入 [2026-10-29 Agent 首轮归档](reports/archive/2026-10-29-agent-round1/)，其中结果以当前复验结论为准。

`methods/` 三份：`DOC-STYLE.md`（怎么写）、`PAPER-WORKFLOW.md`（稿件阶段、版本、交接、日常流程）、
`neoAGu-适配说明.md`（这套管理机制从参考项目改了什么）。

`reports/` 里由脚本生成的报告（文件名含"文档与链接检查""字数报告""文献索引检查"）第一屏必须有
"生成命令:"和"状态:"两行；人写的报告写清日期、对象和"状态:"，两者都不要手抄会过期的数字。
